Scope of Work — Security Panel / Access Control

  • Furnish and install 4-door access control head-end panel (smart hub) at the designated security location
  • Furnish and install card reader at each door position — Front, Back, TD
  • Pull and terminate reader cable — 18/4, no shield (S+) — one run per reader
  • Install door strike — low profile (LP) — on 18/4 cable (orange)
  • Install door contact on 22/2 cable (green)
  • Install maglock and request-to-exit (REX) on 22/4 cable (red), N/O, on the maglock door
  • Terminate, label, and test all field devices back at the panel
  • Verify port-to-door mapping — Port 1-1 = Front; Reader 2 = Back; Reader 3 = TD
  • Program credentials and door groups; demonstrate operation to the owner representative
  • Provide as-built wire schedule and test documentation at closeout
