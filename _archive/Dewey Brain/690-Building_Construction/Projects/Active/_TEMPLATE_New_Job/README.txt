TEMPLATE FOLDER — HOW TO USE
==============================

1. COPY this _TEMPLATE_New_Job folder
2. RENAME it to your job (e.g., "Johnson_Residence_2026")
3. FILL the folders as work happens:

01_Contracts        → Signed agreements, scope docs
02_Photos_Before    → Initial walkthrough photos
03_Estimates_Bids   → Quotes sent to customer
04_Permits          → City permits, inspections
05_Material_Lists   → Parts ordered, vendor lists
06_Invoices         → Bill customer, payment records
07_Photos_After     → Final walkthrough photos
08_Work_Summary     → Notes, issues, callback info

4. WHEN JOB IS DONE → Move entire folder to 2-Projects/Archived/
