📤 Upload a Video (Web UI)

  1. Go to tv.blacktechsolutionscorp.com and Login
  2. Click ➕ Publish (top menu) → Add a video
  3. Drag/drop or click to select your video file
  4. Fill in:
    • Title — name of the video
    • Channel — pick root_channel (default) or create new ones
    • Privacy — Public, Unlisted, or Private
    • Category — Science & Technology (15)
    • Description — SEO text, links, hashtags
  5. Click Publish — PeerTube auto-transcodes to multiple resolutions

📺 Create a Channel

  1. Login → click your avatar (top right) → My library
  2. Click ➕ Add channel
  3. Name it (e.g., energy-tips, electrical-work, behind-the-scenes)
  4. Each channel gets its own URL: tv.blacktechsolutionscorp.com/video-channels/YOUR_CHANNEL

👤 Create Additional Users

  1. Login as admin → Administration → Users → ➕ Add user
  2. Set username, email, password, role (User, Moderator, Admin)
  3. Use for team members, content creators, etc.

🎨 Upload Avatar / Banner (API)

Use POST (not PUT) to the /pick endpoints. Field names are avatarfile and bannerfile.
# Get token (see above), then use Python http.client inside container # POST /api/v1/config/instance-avatar/pick → field: avatarfile # POST /api/v1/config/instance-banner/pick → field: bannerfile # Token must be read from file (shell interpolation truncates it)

🌐 Federation (Follow Other Instances)

  1. Admin → Configuration → Federation
  2. Add follows: videos.danksquad.org, tube.tchncs.de, peertube.social
  3. Your videos also appear in their feeds = more reach

🔌 Embed Videos Anywhere

Every video has an Embed tab — click Share → Embed — paste the iframe into:

  • Blacktech website
  • Social media posts
  • Email newsletters
  • Proposals and estimates

🔴 Live Streaming

  1. Admin → Configuration → Live streams → Enable
  2. Create a live video → get RTMP push URL
  3. Stream from OBS, phone, or any RTMP source
