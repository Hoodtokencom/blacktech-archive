## Key Concepts

### Centralized Control (Traditional Model)
- One company holds the **master keys**
- Your security **depends** on them
- Icon: Building/server rack (representing centralized institution)

### Decentralized / User Control (Web3 Model)
- **You** hold the master keys
- You are in **full control** of your security
- Icon: Golden key (representing individual ownership)

## Summary
The presentation contrasts traditional centralized security (where a single company controls access) with Web3 decentralized security (where users hold their own keys and have full control). This aligns with the "sovereignty" theme — self-custody and user empowerment over digital assets and data.

## Quote (from Ken Shilling's profile)
> "Don't ask for permission to fly. The wings are yours, and the sky belongs to no one."

## Blacktech System Connection
Derrell's note: "This system we have is both" — Blacktech uses a **hybrid model**:
- **Centralized:** Command Center, PayBooks, CRM, email, Cloudflare DNS, Academy — company-controlled infrastructure
- **Decentralized:** Dewey Brain (local file system = source of truth), blockchain pipeline, crypto wallets, self-hosted Pi infrastructure, Web3 elements

Both approaches coexist. Centralized for operations/business, decentralized for sovereignty/ownership.
